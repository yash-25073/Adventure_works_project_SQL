# Adventure_works_project_SQL
## AdventureWorks Sales Data Analysis Using SQL

### Project Overview

This project focuses on analyzing sales data from the AdventureWorks dataset using SQL. The objective is to evaluate business performance through key performance indicators (KPIs), identify sales trends, and analyze product and customer performance.

### Key Analysis Areas

-Sales and profit performance analysis
-Yearly, quarterly, and monthly sales trends
-Top-performing products and customers
-Customer spending analysis
-Order and customer metrics
-Average order value
-Product ranking using SQL window functions

### SQL Concepts & Techniques

-SELECT, WHERE, GROUP BY, ORDER BY
-Aggregate Functions (SUM, AVG, MIN, MAX)
-HAVING Clause
-DISTINCT and COUNT
-LIMIT
-Window Functions (RANK)

### Tools Used

-MySQL
-Microsoft Excel (Dataset Preparation)
